## ⚡ Algorithms

### 1. Sorting & Searching
*   **Binary Search** — Lower/Upper bound, Search Space Reduction
*   **Sorting** — QuickSort, MergeSort, HeapSort, Counting Sort

### 2. Graph Algorithms
*   **Breadth-First Search (BFS) & Depth-First Search (DFS)**
*   **Dijkstra’s Algorithm** (Single-source shortest path)
*   **Bellman-Ford & Floyd-Warshall**
*   **Kruskal’s & Prim’s Algorithms** (Minimum Spanning Tree)

### 3. Dynamic Programming
*   **1D DP:** Fibonacci, House Robber, Climbing Stairs
*   **2D / Grid DP:** Unique Paths, Longest Common Subsequence (LCS), 0/1 Knapsack
*   **Interval & Bitmask DP:** Matrix Chain Multiplication, TSP
